# Data Structure and Algorithm Design

A collection of **data structures and algorithm implementations** developed primarily for studying algorithm design, recursion, sorting, linked structures, queues, stacks, and problem-solving techniques.

The repository contains implementations in **Java and Python**, with several projects organized by algorithmic technique or data-structure category.

## Algorithms

### Divide and Conquer / Recursive Algorithms

The repository currently includes:

- **Knight's Tour** — `Algorithms/Divide & Conquer - Recursive/Knight's tour/KnightsTour.java`
- **Split String** — `Algorithms/Divide & Conquer - Recursive/Split String/Split.py`
- **Strassen Matrix Multiplication** — `Algorithms/Divide & Conquer - Recursive/Strassen's Matrices Multiplying Algorithm/StrassenMatrixMultiplication.java`
- **String to Integer** — `Algorithms/Divide & Conquer - Recursive/String to Integer/StringToInt.java`
- **Sudoku Solver** — `Algorithms/Divide & Conquer - Recursive/Sudoku Solver/SudokuSolver.java`

These projects provide examples of recursive decomposition and backtracking-style problem solving.

### Sorting

Sorting implementations are collected under:

`Algorithms/sorting/Sorts.java`

## Data Structures

### Linked List

The repository contains a **Singly Linked List** implementation:

- `Data Structures/Linked List/Singly Linked List/Node.java`
- `Data Structures/Linked List/Singly Linked List/SinglyLinkedList.java`

### Queue

Queue implementations include:

- Queue implementations under `Data Structures/Queue/Queue 1/` and `Queue 2/`
- Circular Queue — `Data Structures/Queue/CircularQueue.java`
- Priority Queue using an array — `Data Structures/Queue/Piority Queue/Array Approach/PriorityQueue.java`
- Priority Queue using a linked-list approach — `Data Structures/Queue/Piority Queue/Linked List Approach/PriorityQueue.java`

### Stack

The stack section currently contains:

- **Shape Shifter** — `Data Structures/Stack/Shape Shifter/ShapeShifter.java`
- **Postfix Calculator** — `Data Structures/Stack/postfix_caculator/PostfixCaculator.py`

The Shape Shifter implementation also includes a custom `InvalidDataInputException`.

## Languages

The current implementations use:

- **Python** — selected algorithm and stack exercises

## Purpose

This repository is primarily a study collection rather than a single application. Its goal is to provide practical implementations of core computer-science topics and to make algorithmic ideas concrete through code.

Topics currently represented include:

- Recursive algorithms
- Divide and conquer
- Backtracking/problem solving
- Sorting
- Linked lists
- Queues
- Priority queues
- Circular queues
- Stacks
- Expression evaluation

## Current Status

The repository is an evolving collection of implementations. The structure is intentionally organized by topic so that individual algorithms and data structures can be studied independently.
